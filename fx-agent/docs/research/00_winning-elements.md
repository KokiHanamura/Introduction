# FX で勝つための要素 — 全体マップと分析（v1 / 2026-10-06）

> このドキュメントはエージェント設計の土台となる調査メモ。数字の出典は末尾。
> 「出典確認済」= このセッションで Web 上の一次情報を確認したもの、「既知の文献」= 確認は文献知識ベース（要再確認）。

---

## 0. 前提: 「必ず勝つ」は存在しない。設計目標を言い換える

| 事実 | 数字 | 意味 |
|---|---|---|
| EU 各国当局の分析で、CFD（FX 含む）の個人口座の **74〜89% が損失** | 平均損失 €1,600〜€29,000/人 | 何もしなければ「負ける側」が多数派（出典確認済: ESMA 2018） |
| ブラジルの先物デイトレーダーで 300 日以上続けた人の **97% が損失**、最低賃金以上を稼げたのは 1.1% | 「続けても上達した証拠なし」 | 経験を積むだけでは勝てない。**検証と改善の仕組み**が要る（出典確認済: Chague ほか） |
| FX は相手がいるゼロサム（スワップ除く）から、さらにスプレッド・スリッページが引かれる | 期待値 0 の手法は **コスト分だけ確実に負ける** | 「なんとなく 5 割勝てる」では勝てない |

そこで、このエージェントの目標を次のように定義する:

> **正の期待値（エッジ）を、検証で確かめ、破産しない資金管理で、ルール通りに実行し続ける。**
> 勝ち = エッジ × 生存 × 実行。どれか 1 つが 0 なら結果は 0。

期待値の式（1 トレードあたり、R = 損切り幅を 1 とした単位）:

```
期待値(R) = 勝率 × 平均利益(R) − (1 − 勝率) × 平均損失(R) − コスト(R)
損益分岐勝率 = 1 / (1 + 損益比)       例: 損益比 2.0 なら 33.3% を上回れば黒字
```

勝率は単独では無意味。**勝率と損益比のセット**、そして **コスト込み** で評価する（`fxagent/metrics.py` は両方を必ず並べて出す）。

## A. 優位性（エッジ）の源泉 — 何で勝つのか

手法は「なぜそれで儲かるのか（誰が損をしているのか）」を説明できるものほど持続しやすい。
FX で学術的・実務的に存在が議論されてきた源泉:

| 源泉 | 中身 | 時間軸 | 注意点 |
|---|---|---|---|
| **トレンド / モメンタム** | 上がっている通貨は上がり続けやすい（時系列モメンタム） | 数週〜数か月 | FX を含む多資産で確認されてきた（既知の文献: Moskowitz, Ooi, Pedersen 2012）。転換点で大きく負ける・長いレンジで削られる |
| **キャリー** | 高金利通貨買い・低金利通貨売りでスワップを得る | 数か月〜 | 平時はコツコツ、リスクオフで急落（「階段を上ってエレベーターで落ちる」。既知の文献: Brunnermeier, Nagel, Pedersen 2008）。円は典型的な調達通貨 |
| **バリュー** | 購買力平価などからの乖離は長期で修正される | 年単位 | 個人の短期売買には向かない。大局観として使う |
| **平均回帰（レンジ）** | 短期の行き過ぎは戻る | 分〜日 | 低ボラ・レンジ相場でのみ機能。トレンド発生で損失が大きい（逆張りの損切り遅れ） |
| **時間帯・季節性** | 東京/ロンドン/NY でボラと値動きの性質が違う。仲値（9:55 JST）、ロンドンフィックス（16:00 London）、月末・四半期末リバランス | 分〜時間 | 有名になると消える。コストに負けやすい小さいエッジ |
| **イベント** | 雇用統計・CPI・中銀会合・要人発言・介入 | 分〜日 | スプレッド拡大・滑りで検証より悪化する。介入は円で特に重要（2022・2024 年に実弾介入） |
| **ボラティリティ・レジーム** | 低ボラの後に高ボラ（ブレイク）、高ボラは持続しやすい | 時間〜週 | 方向ではなく「いつ戦うか」のフィルタとして有効なことが多い |

**エージェントの方針**
- 手法を持ち込むときに「エッジの源泉」を 1 行で書かせる。書けない手法は過剰最適化の疑いが強い
- 「チャートパターン」「インジケーターのクロス」単体は、コストを入れると優位性が消えることが多い → ①で必ず確認
- エッジは時間とともに劣化する（後述 L）

## B. 検証（①）— その優位性は本物か

**一番の敵は「過剰最適化」**。パラメータやフィルタを何十通りも試せば、ランダムな手法でも過去データ上は勝てるものが必ず見つかる
（出典確認済: Bailey & López de Prado — Deflated Sharpe Ratio / Probability of Backtest Overfitting）。

検証で必ず見る指標（`python3 -m fxagent backtest` が全部出す）:

| 指標 | 見る理由 | 目安 |
|---|---|---|
| トレード数 | 少ないと全部運 | 最低 100、できれば 300+ |
| 勝率 と **損益分岐勝率** | 勝率単体は無意味 | 勝率 > 損益分岐勝率 |
| プロフィットファクター（PF） | 総利益 / 総損失 | コスト込みで 1.2〜1.3 以上が実用ライン、2 超は疑う |
| 期待値（R・pips）と **t 値** | 偶然と区別できるか | t ≥ 2 |
| 最大連敗 | 心理的に耐えられるか | モンテカルロ 95% タイルで見る |
| 最大ドローダウン | 資金が耐えられるか | 同上。バックテストの値は楽観的 |
| リカバリーファクター | 総利益 / 最大 DD | 高いほど効率的 |

検証の落とし穴チェックリストは [`01_validation-pitfalls.md`](01_validation-pitfalls.md)。要点:
未来参照 / コスト過小 / 同一足の SL・TP 判定 / サンプル不足 / 単一相場環境 / 多重検定 / パラメータの尖り / データ品質（タイムゾーン・欠損）。

## C. 負けパターン分析（②）

負けは 2 種類に分けて扱う:
1. **手法通りの負け**（エッジがあっても一定確率で起きる。減らそうとしない）
2. **条件の悪い負け**（特定の時間帯・ボラ・トレンド逆行などに偏っている → 見送りで削れる）

`python3 -m fxagent analyze` が自動で切る条件:
セッション / 時間 / 曜日 / 売買方向 / ATR 水準（ボラ）/ 上位トレンドとの順逆 / MA からの乖離 / シグナル足の大きさ / 直前トレードの勝敗、
さらに MFE/MAE（含み益・含み損の最大）から「一度 +1R まで行って負けた」「損切りギリギリで勝った」を診断する。

今後足すべき特徴量（優先順）: 経済指標までの時間 / 指標直後か / 月末・週末 / 仲値・フィックス前後 / 相関通貨（DXY・クロス円）の方向 / スプレッド実測。

---

## D. 改善（③）— ルールは足すより削る

- 改善案は **前半データで発見 → 後半データで検証**（`analyze` が自動で 70/30 分割して判定）
- 試した条件の数で有意水準を厳しくする（Bonferroni）。デモでも「金曜を見送る」が前半で p=0.002 なのに後半で再現せず却下された — これが過剰最適化の典型
- フィルタを足すとトレード数が減る。期待値が上がっても **総利益・統計的信頼度が下がる** ことがある
- 改善の種類: 見送りフィルタ / 損切り幅（ATR 倍率）/ 利確幅 / 建値移動 / 時間決済 / 分割決済。どれも同じデータ・同じコストで前後比較
- パラメータは「最高値」ではなく「周辺でも崩れない台地」を選ぶ

## E. リスク・資金管理 — 生き残ること

エッジがあっても、資金管理を誤れば破産する。逆に、資金管理は唯一「100% 自分で決められる」要素。

| 項目 | 推奨 | 根拠 |
|---|---|---|
| 1 トレードのリスク | 口座の 0.5〜1%（最大 2%） | 10 連敗しても 1% なら -9.6%、5% なら -40% |
| ロット計算 | `ロット = 残高 × リスク% ÷ (損切り pips × pip 価値)` | 損切り幅が変わってもリスク額を一定に |
| リスク%の決め方 | モンテカルロ 95% タイルの最大 DD が許容 DD に収まる値 | `montecarlo.risk_for_max_dd`（ルールブックに自動反映） |
| ケリー基準 | 使うならハーフ〜クォーター・ケリー | フル・ケリーは推定誤差で過大になり DD が深すぎる |
| 日次・週次の損失上限 | 例: 1 日 -2%・1 週 -5% で停止 | ティルト防止 |
| 通貨の重複 | USDJPY 買い + EURJPY 買い + GBPJPY 買い = 実質「円売り 3 倍」 | 相関を合算してリスク管理 |
| レバレッジ | 実効レバレッジで管理（国内上限 25 倍は上限であって目安ではない） | 出典確認済: 国内個人は最大 25 倍 |
| 窓・週末・指標 | 週末持ち越し・指標またぎは損切りが滑る前提で | 窓開けはバックテストでも始値約定で再現している |
| 破産確率 | ドローダウン限界（例 30%）を超える確率を出す | `montecarlo.simulate` の `prob_dd_over_limit` |

## F. 執行・コスト

| 項目 | 内容 |
|---|---|
| スプレッド | 時間帯で変わる。NY クローズ前後（日本時間早朝）・指標時は数倍〜数十倍に広がる |
| スリッページ | 逆指値（損切り）は不利に滑る。指標時は特に |
| スワップ | 長期保有では無視できない。マイナススワップ側の保有コスト |
| 約定方式・ブローカー | 約定拒否・リクオート・約定力。デモと本番の差 |
| 取引回数 | 回数が多いほどコストの比重が上がる。スキャルピングはコストに負けやすい |

**バックテストのコストは実口座のスプレッドで設定し、さらに +50% で再計算しても期待値がプラスかを見る。**

## G. 心理・行動（④の中心）

人間の脳はトレードに向いていない。典型的なバイアスと、データで検出する方法:

| バイアス・ミス | 中身 | `fxagent journal` での検出 |
|---|---|---|
| **プロスペクト理論 / ディスポジション効果** | 利益は早く確定し、損失は先延ばし（既知の文献: Shefrin & Statman 1985, Odean 1998）| 損切り後退（-1.2R 超）・利小損大・早すぎる利確 |
| リベンジトレード | 負けを取り返そうと即エントリー | 負け後 30 分以内の再エントリー |
| 負け後のロット増 | 取り返し・ナンピン | 負け直後のサイズ > 中央値 × 1.5 |
| オーバートレード / 過信 | 取引回数が多いほど成績が悪い（既知の文献: Barber & Odean 2000） | 1 日の通常回数超え |
| ティルト | 連敗で判断が荒れる | 2 連敗以上直後のトレード |
| FOMO・焦り | 置いていかれる恐怖で飛び乗る | emotion 列 |
| ルール外エントリー | 検証していない条件で入る | followed_plan 列 |
| 損切りを置かない | 1 回で全てを失う | stop 列の欠損 |

対策は「気をつける」ではなく **判定可能な行動ルール**（例:「2 連敗でその日は終了」）にして⑤に入れる。

## H. 記録（ジャーナル）

分析できるのは記録したものだけ。`journal/template.csv` の列:

`trade_id, open_time, close_time, pair, direction, entry, exit, stop, target, size, pnl, setup, followed_plan, emotion, notes`

- **stop / target**: R 倍数の計算、損切り違反・早すぎる利確の検出に必須
- **setup**: 手法ごとの成績比較（どの手法が本当に稼いでいるか）
- **followed_plan / emotion**: 行動ミスの検出に必須。エントリー時に記録（後付けは美化される）
- 最低 30 件で傾向、50〜100 件で判断

## I. ルール化（⑤）

ルールブックの構成（`python3 -m fxagent rulebook` が下書きを作る）:
エントリー（チェックリスト）/ 見送り / 損切り / 利確 / 資金管理 / 停止条件 / 行動ルール / 見直し周期 / 各ルールの根拠数値。

原則: **すべてのルールに根拠の数字を付ける。根拠が無いものは「仮説」と明記**。裁量の余地を減らすほど④の検出が効く。

## J. 相場環境・ファンダメンタルズ

テクニカル手法でも「どの環境で機能するか」を知っておく必要がある。

| 要素 | 影響 |
|---|---|
| 金融政策の方向性の差（金利差） | 中長期トレンドとキャリーの主因。日米金利差と USDJPY |
| リスクオン / オフ | 円・スイスフランは逃避先として買われやすい |
| 経済指標カレンダー | 雇用統計・CPI・FOMC・日銀会合・ECB。直前直後はノイズとコスト増 |
| 為替介入 | 円では財務省の介入で数円単位の急変（2022・2024）。介入警戒水準では逆張りショートの損切りが飛ぶ |
| 地政学・選挙 | 窓開け、ボラ急拡大 |

エージェントへの組み込み: まずは「指標前後・介入警戒時は見送り」を特徴量化して②で効果を測る。ニュース解釈を AI の裁量で売買判断に使うのは、検証できないので後回し。

## K. 税・規制・ブローカー（日本）

| 項目 | 内容 |
|---|---|
| 税金 | 「先物取引に係る雑所得等」として **申告分離課税 20.315%**（所得税 15% + 復興特別所得税 0.315% + 住民税 5%）（出典確認済） |
| 損失繰越 | 確定申告すれば翌年以降 3 年間繰り越せる（既知の制度。要確認） |
| レバレッジ | 個人は最大 25 倍（出典確認済） |
| ロスカット・追証 | 急変時はロスカットが間に合わず口座がマイナス（追証）になり得る |
| ブローカー | 国内登録業者か、信託保全、スプレッド・約定力・API の有無 |

税引き後で考えると、必要な期待値はさらに上がる。

## L. 継続運用 — エッジは劣化する

- 実運用の成績を、バックテストの分布（モンテカルロ）と比較し続ける
- **停止条件**を事前に決める: 実運用の DD がモンテカルロ 95% タイルを超えたら停止して再検証
- 50 トレードごと / 四半期ごとに ①〜⑤ を回し直す
- 相場環境（ボラ水準・トレンド/レンジ）が検証期間と大きく違う時はロットを落とす
