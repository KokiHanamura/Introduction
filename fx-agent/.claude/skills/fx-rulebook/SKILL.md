# ⑤ 自分専用ルールブック: $ARGUMENTS

1. 下書きを生成:
   `python3 -m fxagent rulebook --trades <trades.csv> --journal <journal.csv> --strategy-desc "<手法の一文説明>" --target-dd <許容DD%>`
   - 許容 DD（口座の何 % まで耐えられるか）はユーザーに聞く。不明なら 20%
2. 下書きを次の構成に整える（`docs/rulebook.md` に保存。過去版は git 履歴で追う）
   - **エントリー**: チェックリスト形式（全部 Yes なら入る）
   - **見送り**: 検証で「採用」になった条件 + 記録分析で見つかった行動ルール
   - **損切り**: 置き方・動かしてよい条件（建値移動のみ等）
   - **利確**: 指値の位置・途中決済の条件
   - **資金管理**: 1 トレードのリスク %、1 日/1 週の損失上限、連敗時のロット調整
   - **停止条件**: モンテカルロ 95% タイルの DD を超えたら取引停止して再検証
   - **見直し**: 50 トレードごと / 四半期ごとに ①〜④ を回す
3. 各ルールの横に根拠（どのレポートのどの数字か）を書く。根拠の無いルールは「仮説」と明記
4. 「このルールブックは将来の利益を保証しない」を冒頭に残す
