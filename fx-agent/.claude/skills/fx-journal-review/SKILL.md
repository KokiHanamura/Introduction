# ④ トレード記録の分析: $ARGUMENTS

1. 記録が `journal/template.csv` の形式か確認。足りない列があれば何が検出できなくなるか伝える
   （stop が無い → 損切り違反が分からない、emotion が無い → 感情起因のミスが分からない 等）
2. `python3 -m fxagent journal --journal <path>` を実行
3. 出力のミス Top5 について、ユーザーの言葉で書き直す
   - 何回やっているか / いくら失っているか / 該当時と通常時の勝率差
   - **対策は「行動ルール」として 1 行で**（「気をつける」ではなく「2 連敗でその日は終了」のように判定可能な形）
4. 自動検出に無い観点（ナンピン、指標発表またぎ、週末持ち越し、建値撤退の多さ、手法ごとの成績差）も
   CSV を pandas で直接集計して確認する
5. 件数が 30 未満なら「傾向の示唆」にとどめ、断定しない
6. 結果を `docs/plans/.../journal_review.md` に残し、`/fx-rulebook` を提案する
