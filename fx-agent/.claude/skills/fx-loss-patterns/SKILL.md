# ② 負けパターンの洗い出し: $ARGUMENTS

1. `python3 -m fxagent analyze --trades <trades.csv>` を実行
2. 出力の「期待値が低い条件」を読み、次の観点で整理する
   - **件数が十分か**（20 未満は参考外）、**p 値**（0.05 未満でも試した条件数が多ければ偶然の可能性）
   - **負け全体に占める割合**（期待値が悪くても件数が少なければインパクトは小さい）
   - 損切り・利確の診断（MFE/MAE）: 「一度 +1R に行ってから負けた」「損切りギリギリで勝った」の割合
3. 自動特徴量で表せない仮説（経済指標前後、ロンドンフィックス、月末、窓開け、ニュース、相関通貨）があれば、
   特徴量を `fxagent/indicators.py` に足して再分析することを提案する
4. 結果を `docs/plans/.../loss_patterns.md` に「条件 / 根拠の数字 / 信頼度（高・中・低）」の表で残す
5. 次の一手として `/fx-improve` を提案する
