# ③ 手法の改善: $ARGUMENTS

原則: **ルールは足すより削る**。データで効果が確認できた条件だけを残す。

1. `python3 -m fxagent analyze --trades <trades.csv>` の「改善案」表を読む
   - 「採用」= 前半で有意（多重検定補正後）かつ後半でも改善
   - 「保留」= 後半で改善したが統計的に弱い → データを増やして再確認
   - 「却下」= 後半で再現しない → 過剰最適化。採用しない
2. 損切り・利確の診断から、パラメータ変更案（ATR 倍率、建値移動、時間決済）を作り、
   `/fx-backtest` と同じ手順で **変更前後を同じデータ・同じコストで比較**する
3. 改善案ごとに「期待値の変化 / トレード数の減少 / 最大 DD の変化 / OOS での再現」を表にする
   - トレード数が半分以下になる改善は、期待値が上がっても総利益と統計的信頼度が下がる点を明記
4. 試した案の総数を記録する（`docs/plans/.../improve.md`）。後から見て「何個試して何個残ったか」が分かるように
5. 採用した案を反映した戦略で再度バックテストし、`/fx-rulebook` に渡す
