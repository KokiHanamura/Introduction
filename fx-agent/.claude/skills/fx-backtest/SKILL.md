# ① 手法のバックテスト: $ARGUMENTS

`.claude/rules/fx-research.md` に従う。

1. **手法をルールに落とす**。曖昧な表現（「強いトレンド」「いい形」）は数値条件に言い換え、ユーザーに確認する
   - エントリー条件 / 損切り / 利確 / 決済の時間制限 / 通貨ペア / 時間足
2. **データを確認**: `data/` に該当 CSV があるか。無ければ `docs/research/03_data-sources.md` を示して用意してもらう
3. **戦略を用意**: 既存（`fxagent/strategies.py` の `STRATEGIES`）で表せなければ同じ形の関数を追加し、
   未来参照していないことを示すテストを `tests/` に足す
4. **実行**:
   `python3 -m fxagent backtest --data data/<file>.csv --strategy <name> --param k=v ... --pip-size <0.01|0.0001> --spread <pips> --slippage <pips>`
   - コストはユーザーの口座の実スプレッドに合わせる（不明なら主要ペアの平常時 0.2〜1.0 pips + スリッページ 0.2〜0.5 pips）
5. **頑健性**: 主要パラメータを ±20〜50% 動かして再実行し、成績が崩れないか表にする。期間を前半/後半に分けても確認
6. **報告**（当日の `docs/plans/.../` に `backtest_<手法>.md`）:
   - トレード数・勝率（と損益分岐勝率）・PF・期待値（R と pips、t 値）・最大連敗・最大 DD
   - モンテカルロ 95% タイルの DD・連敗 → 「この手法を使うなら覚悟すべき数字」
   - 判定: 「優位性あり（候補）」「偶然と区別できない」「優位性なし」のどれか。理由を 1 行で
7. 次の一手として `/fx-loss-patterns` を提案する
